## 🌸 About

This is my personal photography and videography portfolio, built to showcase my creative work, experiences and passion for capturing moments.

I'm **Divya Singh**, a Mumbai-based photographer and videographer who loves documenting events, candid moments, celebrations and stories through the lens.

The website combines an editorial aesthetic with interactive elements to create an immersive visual experience.

## ✨ Features

- **Photography Gallery** – Explore photographs with interactive category filters.
- **Image Lightbox** – View photographs in a full-screen gallery with navigation.
- **Videography Showcase** – Interactive video previews and playback.
- **Creative Journey** – Highlights of experiences, projects and milestones.
- **Visual Stories** – Curated photography collections and storytelling.
- **Scrapbook Section** – A personal collection of memories and favourite frames.
- **Interactive Animations** – Smooth transitions, hover effects and animated elements.
- **Responsive Design** – Optimized for desktop and mobile screens.
- **Contact Section** – Easy access to connect and collaborate.

## 🌐 Deployment — GitHub Pages

This portfolio is hosted using **GitHub Pages**.

To deploy your own version:

1. Fork or clone this repository.
2. Ensure the main HTML file is named `index.html`.
3. Push your files to the `main` branch.
4. Navigate to **Settings → Pages**.
5. Under Build and Deployment, select **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Click **Save**.

Your website will be published at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
